# 论文图表规范

依据作者确定的画图原则整理，适用于后续绘图、表格与对应 LaTeX 修改。

## 版式与位置

- 本稿采用 ACM `acmart` 的 `acmsmall` 单栏格式。
- Figure caption 放在图下方，Table caption 放在表上方。
- 图表尽量靠近正文首次引用处，使用 `acmart` 默认浮动与排版。
- 不自行压缩间距或修改模板。

## 图内内容

- 只保留理解图所必需的面板标题、标签、坐标轴、必要基线、极简图例和关键数字。
- 样本范围、统计方法、基线含义、结果解释与 caveat 不堆在图内。
- 必要的统计口径与解释放正文；不依赖图内长段文字补救图形本身的歧义。

## Caption

- 只说明图表展示什么、各 panel 是什么。
- 不在 caption 中重复结果解释、统计结论或 caveat；这些放正文。

## 表格

- 使用可编辑的 LaTeX 表格，尽量采用 `booktabs` 风格。
- 少竖线、少冗余说明。
- 只有复杂术语或特殊统计口径需要 footnote。
- 不把 table 截图成 figure。

## 信息分工

**图负责视觉比较，表负责精确数值，正文负责解释和结论；三者不要重复表达同一件事。**

新增或修改图表时，先明确它相对于已有图、表和正文的信息增量，再决定呈现形式。
