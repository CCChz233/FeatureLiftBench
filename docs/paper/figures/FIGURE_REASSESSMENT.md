## A：任务类型 × 缠绕机制

- **问题：** 不同提取类型分别覆盖哪些缠绕机制？
- **支持的结论：** 一个提取类型可以涉及多种机制，两种分类描述不同方面的任务结构；具体分布结论以核对后的数值为准。
- **图形：** 静态 Python/Matplotlib 热力图，3 × 4 共 12 个单元格。行依次为 Direct、Adapted、Composite；列依次为 Code dependencies、Data and state、Framework mechanisms、Environment and resources。
- **统计单位：** task ID。机制按附录映射取原标签并集；一个任务在同一上层类别只计一次，可出现在多个类别。
- **分母：** 每行对应提取类型的任务数。单元格为“具有该机制的任务数 / 本行任务数”；各列覆盖率不要求合计 100%。色标固定 0–100%，直接标注计数和百分比，行标签给出 n。
- **信息密度：** 行边际数量同时交代三类提取任务的构成，不再另画三扇区饼图。四类机制是多标签，也不画饼图或 100% 堆叠图。
- **颜色：** 单一蓝色顺序色标、白底；数字标签保证不依赖颜色读取结果。
- **数据现状：** 已只读核对，现有 150 条历史机制标注可与提取类型关联，能生成完整的 12 格矩阵。尚未将这些数值认定为当前冻结任务的最终分类统计。
- **范围限制：** 当前索引在这 150 条中记录了 44 条历史分类来源与冻结版本不同。其余 50 个发布任务的分类来自构建记录，不能直接与前者当作同一审核质量的标注合计。优先对齐共同评测的 150 题并明确图注范围；不将缺失或未测得标签当作确定不存在。
- **绘制前工作：** 核对任务身份、lift 标签及四类机制的证据适用性，完成类内去重。这是对已有本地材料的整理，不要求运行 agent 或 oracle 实验。
- **不足时的处理：** 如果无法支持当前冻结任务的数量表述，正文先保留已有分类定义，暂不发布定量覆盖图；不要以示意数字填充热力图。

可用图注方向：

> Coverage of entanglement mechanisms within each lift type. Each cell reports the number and percentage of tasks with the indicated mechanism, using the row's task count as denominator. Mechanisms are multi-label, so a task can contribute to multiple columns.

正式图注需补充最终采用的任务范围和标注版本。该图不包含模型成功率，不推断某类更难或某种机制导致失败。

## B：功能结果与任务通过频次

- **问题：** 六配置的结果结构，以及任务层面的通过差异。
- **左面板：** 六条水平堆叠条，每条 150 题，互斥类别沿用 Pass、Missing、Build、Public、Hidden、Isolation。按现有顺序排列后端，图中直接区分通过、未交付和首个失败阶段。
- **右面板：** 0–6 个配置通过的七个频次柱，计数为 28、7、9、22、36、31、17。使用单色、零起点；说明 28 题没有配置通过、17 题六配置均通过，105 题结果混合。
- **支持的结论：** 总体功能能力仍有限，失败阶段随配置而不同，任务之间的成功覆盖也有差异。门禁结果不等于经确认的语义根因。
- **图表分工：** 主结果表提供精确成功率与 Wilson 区间；图提供结果结构和分布。RQ3 直接引用本图右面板，无需取消该研究问题。
- **附录承担：** 非互斥 gate flags 的精确数量及分母继续保留在已有附表中；正文一句解释 Isolation residual，不另加一张图重复表格。
- **关键边界：** 首个结果的分母为 150，重叠 gate flags 的分母为 829 个已交付产物，不能混用。频次统计保留全部任务并与七个缺陷候选的敏感性分析交叉引用，不能称 28 题均为有效难题。
- **数据充分性：** 900 个已有 model–task 结果，150 个任务的通过频次，均有现成绘图导出数据和检查记录，无需新增实验。

## C：配对提取产物

- **问题：** 两个配置在相同任务上都通过时，是否仍交付不同大小、不同直接复制程度的产物？
- **图形与数据：** 保留两个散点面板，各 97 个同题观测点；横轴 Luna、纵轴 Pro，加等值线。沿用已导出的旧图 5 坐标方向。
- **尺度：** RRES 两轴使用对数尺度，数据均为正且保留长尾；Copy 两轴使用线性尺度，显示 0–1，保留零值。每个面板 x/y 范围一致。
- **支持的结论：** 满足相同功能要求的产物，仍可能在大小和来源重叠方面不同。较小或较少复制不直接意味着更高质量。
- **图表分工：** 配对汇总表保留中位数、任务内差值和方向计数；散点图展示个体差异、偏离等值线的方向及分布。
- **优先级：** 三张图中优先保留，直接支撑 FeatureLiftBench 区分功能成功与提取 footprint 的设计。
