## 现在正文四张表各回答什么

1. **数据集交叉分布**：任务类型是否与构建分组混在一起？为 RQ3 的调整分析铺垫。
2. **功能主结果**：完成了多少任务，区间多宽，在两组任务上表现如何？
3. **配对产物比较**：同样成功的任务上，产物大小和源代码重叠是否有一致差异？
4. **相关工作对照**：已有实现如何提供、交付什么、在哪个边界验证？

配对表的新增统计直接汇总原有共同通过任务：Pro/Luna 的 RRES 较高/较低/相等计数为 85/10/2，Copy 为 76/18/3；Flash/Luna 分别为 85/6/1 和 75/14/3。“同题差值的中位数”与“两组中位数相减”是不同统计量，表注已区分。较高不代表质量更好。

## 第二轮：独立阅读与压缩后的可读性

表数维持九张。本轮发现并修正了以下问题：

- 配对表原先把两个中位数写作 `A/B`，可能误读为比值；方向计数也挤在一格。现在按 Pro/Luna、Flash/Luna 分块，分别列出双方中位数、差值中位数以及正/负/零差值的任务数。增加列数用于消除歧义，不增加新的指标。
- 主结果表明确 `Solved, n (%)` 和置信区间的百分比单位。难度表首列改为 Task group，补明 0–6 是通过的后端数，单元格是任务数。
- 首败表解释 Missing 及 gate 顺序；独立 gate 表解释 Delivered 分母和失败标记不等于测试已执行，避免仅凭表格把计数理解为独立根因。
- 回归表按两个拟合范围分块，去掉每行重复的 Fit 列；保留同一组数值和区间。
- 产物分布明确 n 是通过数、方括号是 Q1/Q3，正文将含糊的“interquartile range”改为第一/第三四分位数。
- RQ4 正文不再逐个复述表内中位数，改为解释同题差异的一致性；相关工作末列改为 Evaluation target，以匹配其实际内容。
- 敏感性段落把后端名和对应通过率写在一起，避免读者在两串列表之间来回寻找对应关系。

主结果、既有中位数、配对任务集合、方向计数、回归系数及区间均未因这轮调整改变。图表的数值重复可服务于查阅，但正文应解释发现而不再朗读表格。

附录保留失败阶段、独立 gate、频次分布、产物分布、回归五张表。前两张的区分是统计口径所需；不为追求表数更少而合并互斥与非互斥结果。图的精确数据表仍有复核价值；后续完成图后可再按篇幅决定哪些数据仅放补充材料。
