# Agent 失败原因（一表一说）

> 冻结 Python-150 · 四模型 · Functional Pass@1 主指标 · 2026-08-06

## 失败卡在哪一关

四模型合计 **356** 次失败的首败分布：

| 首败阶段 | 次数 | 占失败 | 典型含义 |
| --- | ---: | ---: | --- |
| **Public** | **204** | **57%** | 主路径契约没做对 |
| **Hidden** | **116** | **33%** | 主路径过了，边界/状态/接口没闭合 |
| Build | 23 | 6% | 安装或导入失败 |
| 其他 | 13 | 4% | 未交卷、无评测、Isolation 等 |

对照通过率：DeepSeek **66%** ≫ Qwen ≈ **39%** ≫ GPT-OSS **18%**。

## 怎么读

当前 agent 大多能装上包、摸到相关代码，真正拉开差距的不是 Build 或 Isolation，而是 **公开契约主路径（Public）** 和 **更深行为/接口闭包（Hidden）**：弱模型往往主路径就站不住，强模型更常 public 过了仍在 hidden 上因缺 API、缺依赖、缺 registry/资源字段或过早宣布完成而失败；即便 Functional 通过，强模型（尤其 DeepSeek）也往往靠宽拷贝换分，而不是紧凑解耦。
