## 汇报三句话

1. **Benchmark 有效：** 同条件下 Pass@1 从 18% 到 66%，区分度明显。  
2. **排名：** DeepSeek（66%）≫ Qwen（39%）≫ GPT-OSS（18%）。  
3. **瓶颈：** 常卡在契约/Hidden，不在找文件；主分必须看 Functional，不能看 Agent 是否跑完。
