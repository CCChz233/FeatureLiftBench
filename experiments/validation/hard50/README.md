# Hard-50 Validation Evidence

> **Documentation status: reference · Last verified: 2026-08-29**

This directory is the canonical local home for raw Hard-50 calibration,
copy-heavy swap, pilot-gate, and remaining-task experiment evidence. The large
run payloads are intentionally ignored by Git; this boundary document,
maintenance inventory, migration ledger, and content digests are tracked.

Do not promote results from this directory into current reporting solely because
they are stored here. Current suite identity and report eligibility remain
governed by `docs/STATUS.md`, the Hard-50 selection ledger, and the active freeze.

The 2026-08-29 content-preserving migration from the experiment root is recorded
in `experiments/registry/repository_maintenance_20260829.md` and
`experiments/registry/bundle_ledger.json`.
